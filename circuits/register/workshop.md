A register holds a number so a machine can remember it. Use it to keep a value such as a speed setting, the last key pressed, or a score that must survive until the next change.

Set the data inputs to the number you want and hold them steady until after the write. The outputs always show the stored number. The write input must be on for exactly one tick, so put a button or switch through a one-tick pulse maker first. A second tick would flip the stored number back. The memory starts at zero.
