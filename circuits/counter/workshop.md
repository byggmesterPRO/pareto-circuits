A counter keeps a running total of how many times something has happened, such as laps on a track or items passing a sensor.

The count input adds one each time it is pulsed, and the reset input sets the count back to zero. The outputs show the count. Both inputs must be on for exactly one tick, and not in the same tick. A button or switch is too slow, so send it through a one-tick pulse maker first. Holding an input on for longer than one tick gives a wrong count. The count starts at zero.
