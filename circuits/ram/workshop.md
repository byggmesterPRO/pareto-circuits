A RAM stores many numbers at once, each in its own numbered slot. Use it for a lookup table, a list of stored settings, or the working memory of a small computer.

Set the address inputs to the slot you want, and its number is always shown on the outputs. To store a number, set the data inputs to it and pulse the write input for exactly one tick. The address and data must stay steady until after the pulse. A button or switch is too slow, so send it through a one-tick pulse maker first. All slots start at zero.
